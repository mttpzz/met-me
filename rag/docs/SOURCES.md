# RAG source documents

The PDFs indexed by the RAG pipeline are not committed to this repository
(copyright and repo-size reasons). Download the documents below into
`rag/docs/` before running the bot — the RAG index (`rag/index/`) is built
automatically from whatever PDFs are present in this folder on first run.
